# The-Developers-Arena_task-7
# Statistical Business Analysis

## Project Overview

This project applies statistical techniques to analyze business sales data using Python. It includes descriptive statistics, hypothesis testing, correlation analysis, confidence intervals, and regression analysis to generate business insights.

---

## Objectives

- Calculate descriptive statistics.
- Analyze data distribution.
- Perform hypothesis testing.
- Find correlations between variables.
- Calculate confidence intervals.
- Build a linear regression model.
- Provide business recommendations.

---

## Dataset

- **business_data.csv** – Business sales data
- **customer_churn.csv** – Customer churn data

---

## Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Statsmodels
- FPDF2

## Setup Instructions

1. Install the required libraries.

```bash
pip install -r requirements.txt
```

2. Open Jupyter Notebook.

```bash
jupyter notebook
```

3. Run all cells in `statistical_analysis.ipynb`.

---

## Analysis Performed

- Descriptive Statistics
- Histogram & Density Plot
- Shapiro-Wilk Normality Test
- Pearson Correlation Analysis
- Correlation Heatmap
- One-Sample T-Test
- Independent T-Test
- One-Way ANOVA
- 95% Confidence Interval
- Linear Regression (OLS)
